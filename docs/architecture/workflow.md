# Application workflows

## Student lifecycle

Registration → profile → resume upload → ATS → skills → assessments → tracker → **one** target role → AI roadmap → courses → jobs/drives → apply → review → shortlist → assessment → interview → hire → TPO placement analytics.

## Placement drive

Company/recruiter requests drive → TPO review (approve / reject / reschedule) → eligible students → applications → shortlisting → assessment → interview → selection.

## Messaging graph

Student ↔ TPO, Student ↔ Recruiter, TPO ↔ Recruiter. Conversations are created only when both parties are allowed to talk.
